## 安装静态二进制文件

1. 下载静态二进制归档文件。访问 <https://download.docker.com/linux/static/stable/>，选择你的硬件平台，并下载与你想安装的 Docker Engine 版本对应的 `.tgz` 文件。

2. 使用 `tar` 工具解压归档文件。解压后会得到 `dockerd` 和 `docker` 二进制文件。

   ```shell
   tar xzvf /path/to/FILE.tar.gz
   ```

3. 可选：将二进制文件移动到可执行路径中的目录，例如 `/usr/bin/`。如果跳过此步骤，调用 `docker` 或 `dockerd` 命令时必须提供可执行文件的完整路径。

   ```shell
   sudo cp docker/* /usr/bin/
   ```

4. 启动 Docker 守护进程：

   ```shell
   sudo dockerd &
   ```

   如果需要使用其他选项启动守护进程，可以相应修改上面的命令，或创建并编辑 `/etc/docker/daemon.json` 文件来添加自定义配置选项。

5. 运行 `hello-world` 镜像，验证 Docker 是否安装正确。

   ```shell
   sudo docker run hello-world
   ```

   该命令会下载一个测试镜像，并在容器中运行它。容器运行时会打印一段消息，然后退出。

至此，你已经成功安装并启动了 Docker Engine。

## 使用 systemd 配置 Docker 开机自启

许多现代 Linux 发行版使用 [systemd](https://docs.docker.com/config/daemon/systemd/) 管理系统启动时需要运行的服务。在 Debian 和 Ubuntu 上，Docker 服务默认会开机自启。对于其他使用 systemd 的 Linux 发行版，如果要让 Docker 和 containerd 在系统启动时自动运行，请执行以下命令：

```shell
sudo systemctl enable docker.service
sudo systemctl enable containerd.service
```

如果要停止这种开机自启行为，请改用 `disable`。

```shell
sudo systemctl disable docker.service
sudo systemctl disable containerd.service
```

如果需要添加 HTTP 代理、为 Docker 运行时文件设置不同的目录或分区，或者进行其他自定义配置，请参考 [customize your systemd Docker daemon options](https://docs.docker.com/config/daemon/systemd/)。

## 手动创建 systemd 单元文件

在不使用包管理器、直接安装二进制文件时，你可能希望将 Docker 集成到 systemd 中。为此，可以从 [GitHub 仓库](https://github.com/moby/moby/tree/master/contrib/init/systemd) 获取两个单元文件（service 和 socket），并安装到 `/etc/systemd/system`。

### systemd 单元文件

- [docker.service](https://github.com/moby/moby/blob/master/contrib/init/systemd/docker.service)
- [docker.socket](https://github.com/moby/moby/blob/master/contrib/init/systemd/docker.socket)
